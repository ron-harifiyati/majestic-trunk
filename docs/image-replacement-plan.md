# Image Replacement Plan — what to get and where

Companion to `image-audit.md`. One row per image "slot" the new site needs.

**Do we replace everything?** Effectively yes for content photos — almost all current
ones are third-party or stock (see audit). The good news: as a reseller you can usually
**request official media from each lodge/operator** (they want you selling them), so most
replacements are *permission requests*, not stock purchases.

**Source strategy key:** 🏢 request from partner (lodge/operator media kit) ·
📷 own/commission photography · 🧾 licensed stock (paid) · 🎨 custom graphic

## Recommended order
1. **Brand assets** (logo, favicon, OG) — design first; everything depends on them.
2. **Home hero** — the single most important photo.
3. **Lodge media kits** — email each lodge for official photos + permission (fastest win).
4. **Experience heroes** — request from each operator; commission/shoot the gaps.
5. **Gallery fill** — once heroes are locked.

> Target: ~1 hero per experience (10) + per lodge (5) + home hero + ~8 gallery = **~25–35
> rights-clean images**. Until then, use clearly-labeled placeholders so layout/dev isn't blocked.
