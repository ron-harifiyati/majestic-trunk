# Majestic Trunk Expeditions

Static marketing site for **[majestictrunk.com](https://majestictrunk.com)** — a luxury
safari & expedition operator in Victoria Falls, Zimbabwe.

Built as plain **HTML / CSS / JS** and generated by a tiny, zero-dependency Node script.
No framework, no runtime JavaScript for layout, no backend. Bookings hand off to the
operator's external **Activitar** platform.

---

## At a glance

| | |
|---|---|
| **Stack** | Plain HTML/CSS/JS + a small Node generator (`build.js`) |
| **Dependencies** | None — Node (build) and Python (local serving) only |
| **Content** | JSON files in `src/data/` |
| **Output** | 22 static pages in `dist/` |
| **Booking** | External — Activitar |
| **Hosting** | Static (e.g. Cloudflare Pages) |

---

## Getting started

Requires Node 18+ (generator) and Python 3 (local server).

```bash
node build.js                                   # generate dist/ from src/
python3 -m http.server 8090 --directory dist    # serve it → http://localhost:8090
```

---

## How it works

Content and layout are kept separate: you edit **content** as JSON and **layout** as
templates, then `build.js` combines them into real HTML pages — *one reusable template per
page type, many generated pages.*

```
src/data/experiences.json    ──┐
src/templates/experience.html ─┼──►  node build.js  ──►  dist/experiences/*.html
src/partials/header.html     ──┘                          (one real page per experience)
```

- **Add / edit an experience or lodge** → edit `src/data/experiences.json` or
  `lodges.json`, then rebuild. Never edit `dist/` directly.
- **Change the header, footer, or a layout** → edit `src/partials/` or `src/templates/`
  once; every page updates.
- **Change colors, type, or spacing** → edit the tokens in `src/styles/tokens.css`.

## Folder structure

```
majestic-trunk/
├─ build.js                 # the static-site generator (zero dependencies)
├─ package.json             # build + serve scripts
├─ src/                     # ← everything you edit lives here
│  ├─ data/
│  │  ├─ site.json          #   brand, Activitar URL, year
│  │  ├─ experiences.json   #   the ~10 experiences (one object each)
│  │  └─ lodges.json        #   the ~5 lodges
│  ├─ partials/
│  │  ├─ base.html          #   page shell (<head> + header/footer slots)
│  │  ├─ header.html        #   the one shared header
│  │  └─ footer.html        #   the one shared footer
│  ├─ templates/            #   one template per page type
│  │  ├─ home.html
│  │  ├─ experiences-index.html   experience.html
│  │  ├─ lodges-index.html        lodge.html
│  │  └─ about.html  contact.html  gallery.html  privacy.html
│  ├─ styles/
│  │  ├─ tokens.css         #   design tokens — colors, type, spacing scale
│  │  └─ site.css           #   component styles
│  ├─ js/
│  │  └─ nav.js             #   mobile nav toggle (the only layout JS)
│  └─ assets/img/           #   images (placeholders, pending rights clearance)
├─ dist/                    # generated output (gitignored) — this is what deploys
├─ docs/                    # plan, image audit, booking notes
└─ design-mockups/          # throwaway visual explorations (reference only)
```

## Deploy

Any static host. For **Cloudflare Pages**: build command `node build.js`, output
directory `dist`.
