# Majestic Trunk Expeditions

Static marketing site for **[majestictrunk.com](https://majestictrunk.com)** — a luxury
safari & expedition operator in Victoria Falls, Zimbabwe.

Built as plain **HTML / CSS / JS** and generated by a tiny, zero-dependency Node script.
No framework, no runtime JavaScript for layout, no backend. Bookings hand off to the
operator's external **Activitar** platform.

---

## At a glance

| | |
|---|---|
| **Stack** | Plain HTML/CSS/JS + a small Node generator (`build.js`) |
| **Dependencies** | None — Node (build) and Python (local serving) only |
| **Content** | JSON files in `src/data/` |
| **Output** | 56 static pages in `dist/` |
| **Booking** | External — Activitar |
| **Hosting** | Static (e.g. Cloudflare Pages) |

---

## Getting started

Requires Node 18+ (generator) and Python 3 (local server).

```bash
node build.js                                   # generate dist/ from src/
npm test                                        # filters + generated routes/links/assets
python3 -m http.server 8090 --directory dist    # serve it → http://localhost:8090
```

---

## How it works

Content and layout are kept separate: you edit **content** as JSON and **layout** as
templates, then `build.js` combines them into real HTML pages — *one reusable template per
page type, many generated pages.*

```
src/data/experiences.json    ──┐
src/templates/experience.html ─┼──►  node build.js  ──►  dist/experiences/*.html
src/partials/header.html     ──┘                          (one real page per experience)
```

- **Add / edit an experience or lodge** → edit `src/data/experiences.json` or
  `lodges.json`, then rebuild. Never edit `dist/` directly.
- **Change the header, footer, or a layout** → edit `src/partials/` or `src/templates/`
  once; every page updates.
- **Change colors, type, or spacing** → edit the tokens in `src/styles/tokens.css`.

## Status

Editorial redesign complete — 56 pages, including 26 activity guides,
13 accommodation guides, 8 dining guides, a travel-planning guide. Official sources and review dates
are stored with each listing. Rates are quoted on enquiry rather than displaying
unverified starting prices. The former Inkosi URL is preserved with the verified
Nkosi Guest Lodge name.

The visual system uses Fraunces + Inter, the original Sun & Savanna
sand/terracotta/olive palette, rounded cards, pill buttons and pill navigation. Source and generated-page checks
pass; visual browser verification remains outstanding because computer-use access
was unavailable in the development session.

Outstanding launch work is tracked in [GitHub issues](https://github.com/ron-harifiyati/majestic-trunk/issues),
including rights-cleared photography, verified contacts, product-specific Activitar
links, production privacy content, image optimization and deployment checks.

## Directories and photography

The primary sections are `/experiences/`, `/stay/` and `/eat-drink/`. Stays and dining
use grouped static listings enhanced by `directory.js`. Experiences use one
continuous grid and `experiences.js`, with category, country and time-available
filters, presented as three dropdowns. Without JavaScript all experience cards
remain visible; stay and dining category links remain section anchors. Both controllers
support shareable query parameters, result counts, reset and browser back/forward.
Experience `timeCategory` values are broad planning labels, not promised durations;
variable programmes use an explicit confirmation category.

`src/data/research-backlog.json` records suggested venues that still need direct
verification and are deliberately excluded from public listings. The Boma remains
a single experience entry linked from Eat & Drink. Airport services belong in the
travel guide, separate from town restaurants.

The image manifest is `src/data/media.json`. New destination photographs have
Creative Commons attribution; official venue photographs are local design-preview
assets pending publication permission. Do not treat source attribution as a licence.
See `docs/photography-sources.md`. The generator copies only referenced media and
excludes the older watermarked, stock-preview and wrong-location images.
